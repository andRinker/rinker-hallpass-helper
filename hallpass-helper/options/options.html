HallPass Helper settings

Set these once. Everything stays in this browser; nothing is sent anywhere.

You

Type these exactly as HallPass shows them, so they can be filled in for you.

My students

One student per line, "First Last" or "Last, First". Put a line like "Period 3" above each class so the side panel shows the right kids each period.

Bell schedules

One period per line, like "Period 1 8:00-8:50". Times without am/pm from 1:00 to 6:59 count as afternoon.

Which schedule each day

You can switch today's schedule any time from the side panel.

You'll get a notice listing anyone who wasn't back yet. HallPass has to be open in Chrome for this to work.
